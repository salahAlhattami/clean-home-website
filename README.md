# كلين هوم — Clean Home

موقع عربي لخدمات تنظيف المنازل والكنب والسجاد والخزانات في مكة المكرمة.

## التشغيل

الموقع ثابت ولا يحتاج تثبيت حزم أو عملية بناء. مجلد النشر هو `dist/`، ويحتوي على الصفحة والأصول والخطوط والصور. للتشغيل محليًا، شغّل `python3 -m http.server 8080 --directory dist` وافتح `http://localhost:8080`.

## التواصل

رقم الهاتف والواتساب: +966557002574. نموذج الطلب يجهز رسالة واتساب، ولا يرسل رسالة تلقائيًا.

## الصور والهوية

الشعار SVG شفاف. صور الخدمات والأدوات والفريق توضيحية أُعدت لهوية كلين هوم، ولا تمثل توثيقًا للفريق الفعلي أو معدات الشركة.

## التفاعلات

تفاصيل الخدمات، تكبير الصور، استكشاف الأدوات، الطلب السريع، ونموذج طلب متكيف مع الخدمة.

## النشر على GitHub Pages

يتولى الملف `.github/workflows/pages.yml` نشر محتويات `dist/` تلقائيًا عند تحديث `main`، بعد تفعيل GitHub Pages واختيار GitHub Actions مصدرًا للنشر في إعدادات المستودع.
